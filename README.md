# Unstructured Text Analysis and Automated Triage

## Project Overview

This project explores Natural Language Processing (NLP) techniques for analyzing unstructured text data and discovering meaningful topics using machine learning.

The assignment focuses on building an explainable text analysis pipeline using Bag of Words, TF-IDF Vectorization, and K-Means clustering.

## Project Scenario

The project considers approximately 4,000 unstructured user posts and support discussions across four domains:

- Electronics
- Mac Hardware
- Automobiles
- Medical and Health

The objective is to explore automated text categorization and identify important vocabulary patterns.

## Key Objectives

- Clean and normalize unstructured text.
- Perform tokenization and stopword removal.
- Apply stemming and lemmatization.
- Implement Bag of Words (BoW).
- Apply TF-IDF vectorization.
- Discover topics using K-Means clustering.
- Visualize document clusters using TruncatedSVD.
- Explore explainable text classification and document similarity.
